# WeatherRadar Client

This is a command-line client application for interacting with the WeatherRadar API.

## Dependencies

- requests
- rich

## Setup

1. Ensure the WeatherRadar API is installed and running (see API README).
2. *Install required dependencies*
3. ``` pip install requests rich ```

**How to run this API**

From the project root:

``` python client.py ```

## API Endpoint

The client connects by default to:
http://localhost:5000/weatherradar/api/

Make sure the API server is running before starting the client.
